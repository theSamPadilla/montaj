usage: montaj transcribe [-h]
                         [--model {large-v3-turbo-q5_0,large-v3-turbo,tiny.en,base.en,small.en,medium.en,tiny,base,small,medium,large,large-v1,large-v2,large-v3}]
                         [--language LANGUAGE] [--max-context MAX_CONTEXT]
                         [--by-runs] [--fit-pauses] [--json] [--out PATH]
                         [--quiet]
                         input

positional arguments:
  input                 Video or audio file to transcribe

options:
  -h, --help            show this help message and exit
  --model {large-v3-turbo-q5_0,large-v3-turbo,tiny.en,base.en,small.en,medium.en,tiny,base,small,medium,large,large-v1,large-v2,large-v3}
                        Whisper model. Larger = slower + more accurate.
                        English-only (*.en) models are auto-upgraded to a
                        multilingual sibling when language is non-English.
  --language LANGUAGE   Language code (e.g. en, fr, de, es), or 'auto' for
                        whisper-cli language auto-detection. A non-English
                        value upgrades an *.en model to its multilingual
                        sibling.
  --max-context MAX_CONTEXT
                        Cap on prior-text tokens carried between windows
                        (whisper.cpp -mc). Set 0 to disable cross-window
                        context — the reliable fix for the repetition-loop
                        hallucination on long audio (especially non-English).
                        Omit for the whisper default.
  --by-runs             Transcribe each run of voice as its own clip, all of a
                        take's clips in one whisper call, so retakes said back
                        to back are all heard and times do not drift. On by
                        default; false transcribes the whole file in one pass,
                        and a trim spec always does. A file with no voiced run
                        falls back to the whole-file pass. max-context is
                        ignored when on.
  --fit-pauses          For captions: fit word times to the pauses measured in
                        the audio, so a word after a pause starts on the
                        voice. Leave it off for anything that cuts on word
                        times.
  --json                Output result as JSON
  --out PATH            Output file path
  --quiet               Suppress progress output
