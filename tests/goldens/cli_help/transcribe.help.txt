usage: montaj transcribe [-h]
                         [--model {tiny.en,base.en,medium.en,tiny,base,medium,large,large-v3}]
                         [--language LANGUAGE] [--max-context MAX_CONTEXT]
                         [--json] [--out PATH] [--quiet]
                         input

positional arguments:
  input                 Video or audio file to transcribe

options:
  -h, --help            show this help message and exit
  --model {tiny.en,base.en,medium.en,tiny,base,medium,large,large-v3}
                        Whisper model. Larger = slower + more accurate.
                        English-only (*.en) models are auto-upgraded to a
                        multilingual sibling when language is non-English.
  --language LANGUAGE   Language code (e.g. en, fr, de, es), or 'auto' for
                        whisper-cli language auto-detection. A non-English
                        value upgrades an *.en model to its multilingual
                        sibling.
  --max-context MAX_CONTEXT
                        Cap on prior-text tokens carried between windows
                        (whisper.cpp -mc). Set 0 to disable cross-window
                        context — the reliable fix for the repetition-loop
                        hallucination on long audio (especially non-English).
                        Omit for the whisper default.
  --json                Output result as JSON
  --out PATH            Output file path
  --quiet               Suppress progress output
