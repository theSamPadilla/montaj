usage: montaj filler [-h]
                     [--model {tiny.en,base.en,medium.en,tiny,base,medium,large,large-v3}]
                     [--language LANGUAGE] [--window-in WINDOW_IN]
                     [--window-out WINDOW_OUT] [--json] [--out PATH] [--quiet]
                     input

positional arguments:
  input                 Source video file or trim spec JSON from a prior step

options:
  -h, --help            show this help message and exit
  --model {tiny.en,base.en,medium.en,tiny,base,medium,large,large-v3}
                        Whisper model for filler detection. Larger = slower +
                        more accurate. English-only (*.en) models are auto-
                        upgraded to a multilingual sibling when language is
                        non-English.
  --language LANGUAGE   Language code (e.g. es) for transcription and filler
                        matching, or 'auto'. Selects the per-language
                        hesitation-filler set and upgrades *.en models to
                        multilingual.
  --window-in WINDOW_IN
                        Analyse only this window of --input (source seconds),
                        instead of the whole file. Must be paired with window-
                        out; also adds a `cuts` array (the complement of
                        `keeps` within the window, each filler entry carrying
                        the matched word as `text`) to the output.
  --window-out WINDOW_OUT
                        End of the analysis window in source seconds. Must be
                        paired with window-in.
  --json                Output result as JSON
  --out PATH            Output file path
  --quiet               Suppress progress output
