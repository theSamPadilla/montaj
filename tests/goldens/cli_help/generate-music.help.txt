usage: montaj generate-music [-h] --prompt PROMPT
                             [--vendor {gemini,elevenlabs}] [--model MODEL]
                             [--seed SEED] [--with-vocals]
                             [--duration DURATION] [--json] [--out PATH]
                             [--quiet]

options:
  -h, --help            show this help message and exit
  --prompt PROMPT       Text description of the music (genre, mood,
                        instrumentation, BPM)
  --vendor {gemini,elevenlabs}
                        Music vendor to use. ElevenLabs music needs their paid
                        plan.
  --model MODEL         Override the vendor's default model (Gemini default:
                        lyria-3.5, ~68s tracks)
  --seed SEED           RNG seed for reproducible outputs. Gemini only;
                        ignored for ElevenLabs.
  --with-vocals         Allow vocals in the output. Gemini only; ElevenLabs
                        ignores this. Omit for instrumental-only, best under
                        narration.
  --duration DURATION   Seconds. Required for elevenlabs (min 3). Gemini's
                        longer track is trimmed to it with a fade-out, same
                        codec; a shorter one is kept.
  --json                Output result as JSON
  --out PATH            Output file path
  --quiet               Suppress progress output
